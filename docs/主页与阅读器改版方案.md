## 五、踩坑记录（改版时注意）

- `sticky` 的 `top: 0` 是相对**滚动容器的内边距盒**：页面留多少顶部内边距，标题栏上方就有多高一条缝会漏内容 ✓（已修）
- 顶部间距用 `max(env(safe-area-inset-top), 26px)`，**不要相加** —— 相加在 env 不为 0 的机器上会双重计算 ✓（已修）
- 圆点/圆环这类"要对齐"的元素，**用嵌套定位（inset）而不是手算坐标** —— 浏览器与安卓字体度量不同，手算必偏 ✓（已修）
- 写 CSS 变量前先确认它存在：`var(--accent)` 在项目里不存在，会让整条声明失效（背景变透明）✓（已修）
- 改完必须 `npm run typecheck` + 探针跑四个页面看控制台报错 ✓
- 发版流程：升 versionCode/versionName → 构建 → **对比 SHA256 与上一版不同** → 装模拟器 → 复制到桌面并 present ✓
