## 二、版心宽度真正生效（用户反馈"没效果"）

两个原因叠加：

- **滚动模式**：`--reader-width` 默认 720px，在 390px 宽的屏上永远不触发 `max-width` ✗；
  而且滑块 `min={480}` → 永远够不到有效区间 ✗。
  → 下限改 **240**；`.reader-page` 已加 `margin: 0 auto`（比屏窄时居中）。
- **翻页模式**：栏宽是 **JS 分页算出来的**（`screenWidth / columns / columnWidth`，约 60–75 行）✗，
  `--reader-width` 在那里**根本没被读** ✗。
  → 把 `pageWidth` 接进分页计算：`columnWidth = min(可用宽, pageWidth)`。

## 三、页边距在翻页模式生效（用户反馈"只有滚动有效"）

翻页模式分页按 `bodySize`（元素内容宽）算栏宽 ✗ → padding 变量没参与计算 ✗。
→ 分页可用宽改成 `元素宽 − 2 × padding`。
